## 2. วิธีตั้งค่า Google Sheet สำหรับตัวดึงข้อมูล 3 ระดับ

ระบบมีกลไก **Fallback 3 ระดับอัตโนมัติ** เพื่อให้มั่นใจว่าสามารถแสดงผลได้เสมอ:

### ระดับที่ 1 (หลัก): Google Visualization Endpoint (gviz CSV)
ดึงข้อมูลแบบเกือบ Real-time (อัปเดตทันทีเมื่อแก้ไขใน Sheet)
1. เปิดไฟล์ Google Sheet ของคุณ
2. คลิกปุ่ม **"แชร์" (Share)** ที่มุมขวาบน
3. ในหัวข้อ **การเข้าถึงทั่วไป (General access)** เปลี่ยนเป็น **"ทุกคนที่มีลิงก์" (Anyone with the link)** และตั้งสิทธิ์เป็น **"ผู้มีสิทธิ์อ่าน" (Viewer)**
4. กด **"เสร็จสิ้น" (Done)** — แอปจะสามารถอ่านข้อมูลผ่านระดับที่ 1 ได้ทันที

### ระดับที่ 2 (สำรอง): ลิงก์เผยแพร่ไปยังเว็บ (Published to Web CSV)
ใช้สำรองเมื่อเครือข่ายบล็อก gviz endpoint (ข้อมูลอาจมีความล่าช้าประมาณ 5 นาทีตามระบบแคชของ Google)
1. ใน Google Sheet ไปที่เมนู **ไฟล์ (File)** > **แชร์ (Share)** > **เผยแพร่ไปยังเว็บ (Publish to web)**
2. ช่องแรกเลือกแท็บที่ต้องการ (เช่น `ฟอกไต 2569`) และช่องที่สองเลือก **"ค่าที่คั่นด้วยเครื่องหมายจุลภาค (.csv)"**
3. คลิกปุ่ม **"เผยแพร่" (Publish)** แล้วกดตกลง
4. คัดลอกลิงก์ที่ได้ (จะลงท้ายด้วย `output=csv`) ไปวางในหน้า **ตั้งค่า (Settings)** ของแอปพลิเคชัน

### ระดับที่ 3 (ทางเลือกเมื่อถูกบล็อก CORS): Google Apps Script Web App
ใช้เมื่อองค์กรหรือเครือข่ายจำกัดการเรียก CSV ข้ามโดเมน
1. ใน Google Sheet ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
2. คัดลอกโค้ดทั้งหมดจากไฟล์ [`docs/apps-script.gs`](./docs/apps-script.gs) ไปวางแทนโค้ดเดิม
3. กด **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
4. เลือกประเภทเป็น **เว็บแอป (Web app)**
   - **ดำเนินการในฐานะ (Execute as):** ฉัน (Me)
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone)
5. กด Deploy แล้วนำ URL ที่ลงท้ายด้วย `/exec` ไปวางในหน้า **ตั้งค่า (Settings)** ของแอปพลิเคชัน

## 3. ระบบตรวจสอบคุณภาพข้อมูลอัตโนมัติ (Data Quality Audit)

แอปพลิเคชันจะตรวจสอบข้อมูลทุกครั้งที่โหลดหรืออัปเดตโดยอัตโนมัติ:
- **(ก) ตรวจสอบยอดรายงวดเทียบยอดรายเดือน:** ผลรวม 2 งวดของแต่ละเดือนในตารางที่ 1 (COCD และ SOCD) ต้องตรงกับยอดรายเดือนในตารางที่ 2
- **(ข) ตรวจสอบยอดรวมทั้งปีงบประมาณ:** ยอดรวมที่แอปคำนวณได้เองต้องตรงกับแถว `"รวม"` ของ Sheet (เช่น `14,653,522.00 บาท`)
- **(ค) ตรวจจับความผิดปกติรายงวด (Anomaly Detection):**
  - แจ้งเตือนเมื่องวดใดมีค่าเฉลี่ย **บาท/คน** ผิดปกติเกิน **±25%** จากค่าเฉลี่ยของสิทธิเดียวกัน
  - แจ้งเตือนเมื่อ **SOCD และ COCD ในงวดเดียวกันมีทั้งจำนวนคนและจำนวนเงินเท่ากันทุกตัวเลข** (เช่น งวด `20260201` ที่ทั้ง COCD และ SOCD มีผู้รับบริการ `61 คน` และยอดเงิน `145,828.00 บาท` เท่ากัน)
- **(ง) จัดการข้อมูลที่ยังไม่ครบ:** เดือนที่ช่อง `UC` ยังว่างอยู่ (เช่น ส.ค. และ ก.ย.) จะถูกแยกเป็น `null` (ไม่นับเป็น `0`) พร้อมแสดงสัญลักษณ์ **"ไม่ครบ"** บนกราฟและตารางอย่างชัดเจน
